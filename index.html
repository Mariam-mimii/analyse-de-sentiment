🔧 Stack Technique

  • Frontend: HTML5, CSS3, JavaScript (NLP intégré)
  • Backend ML: Apache Spark 4.1.1, Scala 2.13
  • Alternation Python: scikit-learn, NumPy, Pandas
  • NLP: Spark MLlib (Tokenizer, StopWords, TF-IDF)
  • Modèles: Régression Logistique, Naive Bayes, LinearSVC
